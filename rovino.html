RoVino Inventory Management System

A local Flask and SQLite web application built to organize wine and bar inventory through structured records, CRUD workflows, low-stock alerts, restock history, and basic access-control concepts.

View Screens View GitHub Project Back to Portfolio
Built With Python, Flask, SQLite, SQL, HTML/CSS, Bootstrap
Core Workflows Login, dashboard, search, add/update item, low-stock alerts, restock history
Portfolio Signal Database-backed workflow organization relevant to lab inventory, sample tracking, and biology data-support roles.

Workflow

How the app turns inventory actions into trackable records.

Website Screens

The screens show the actual project, not just the code repository.

These screenshots are included so an employer can quickly see the interface, data structure, and workflow logic behind the RoVino project.

Inventory dashboard

Searchable inventory records with low-stock labels and item actions.

The main dashboard organizes inventory by category, displays item-level fields, and surfaces action buttons for editing, deleting, and restocking records.

Access-control concept

Login screen before inventory access.

The login page shows the project was built with controlled access in mind, instead of exposing the inventory dashboard directly.

Data-entry workflow

Add-item form for structured inventory records.

The add-item workflow captures category, item details, quantity, price, alert threshold, and storage location so records can be reused and updated consistently.

Maintenance workflow

Update screen for changing records over time.

The update view keeps inventory maintenance separate from initial entry, which makes the app behave like a real tracking tool rather than a static list.

Activity history

Restock history preserves dated inventory actions.

The restock-history screen keeps a separate record of prior restocking events, including date, item, type, quantity, and a repeat-restock action.

Technical Takeaways

What this project is meant to demonstrate.

Database-backed records

SQLite stores inventory items and supports repeatable retrieval, updates, and restock tracking.

CRUD workflows

The interface supports creating, reading, updating, and deleting records through clear user tasks.

Workflow design

Dashboard, add-item, update-item, and history screens separate the main inventory-management actions.

Research/data-support relevance

The same structure transfers to sample inventories, reagent tracking, lab records, and operational datasets.
